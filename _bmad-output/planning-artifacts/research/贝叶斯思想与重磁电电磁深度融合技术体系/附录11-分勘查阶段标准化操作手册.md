> **SOP边界。** 阶段时长、资源、深度和阈值是带阶段作用域的`Design-assumption/Planned`，不是已验证SLA。诊断门只读取WP2合同；Observed必须绑定Evidence ID、Run ID和manifest。

## 概述

本操作手册给出基于贝叶斯思想与重磁电电磁深度融合技术体系的Planned流程候选。手册覆盖**草查、预研、普查、详查、勘探、生产勘探**六个阶段，并为输入输出、参数、质量控制和验收保留项目级配置接口；其适用性须逐项目验证，不构成已完成体系或应用保证。

> **资源分类边界**：物探后验仅用于靶区优选和靶体体积/潜力情景，不得自动映射为推断、控制、探明资源量或储量。正式分类必须依据适用法规/标准，联合钻孔品位、体积密度、支持尺度、合理开采前景及合资格人员审查。

> **WP4阶段决策门。** 孔数、概率阈值、风险score或阶段名称均不得自动升级资源类别。各阶段只能发布“物探约束靶体潜力情景”和候选行动；行动须以冻结状态—行动—损失合同及校准概率比较“不行动、补测、钻探路径”，并标明唯一币种、基准年、折现和成本时点。未通过独立盲测与合规签署时不得出现正式资源量、储量或可采资源量结论。
>
> **性能与诊断证据门**：本手册中的时长、资源、效率和性能数字均为 `Hypothesis/Planned`；无完整 benchmark manifest 不得标为 `Observed`。MCMC/SMC放行阈值只读取 `validation/wp2-toy/diagnostic-contract.json`，rank-$\hat R$、bulk/tail ESS、关键决策量MCSE、跨模态访问与失败率等 hard gates 必须联合通过，任何单指标不得放行。

**六阶段候选流程说明（Planned）**：按当前文稿作用域列出六个阶段，用于组织候选任务与证据接口；阶段名称和交付物仍须与项目适用法规及委托要求核对：
1. **草查阶段**（1:25万-1:50万）：区域成矿远景评价，筛选成矿带
2. **预研阶段**（1:10万）：靶区优选与可行性研究
3. **普查阶段**（1:5万）：远景区验证与靶区圈定
4. **详查阶段**（1:1万）：矿体定位与资源潜力评价
5. **勘探阶段**（1:2000-1:500）：矿体边界验证与合规分类证据准备
6. **生产勘探阶段**（1:500-1:200）：生产期间探边、探盲与储量升级

## 第一节 草查阶段操作流程（新增）
<!-- WP3-SECTION-STATUS id=A11-stage-1 status=Design-assumption gate=regional-calibration+competing-explanations -->

### 1.1 阶段目标与定位

**阶段目标**：区域成矿远景评价，筛选成矿带，为后续预研工作提供依据

**阶段定位**：勘查全周期的起点，大范围区域筛选阶段

**比例尺要求**：1:25万-1:50万

**预计工期**：3-6个月

**费用接口（Planned）**：按项目范围、币种、基准年、成本时点和不确定性逐项估算；本手册不预设金额区间。

### 1.3 标准操作流程

#### 1.3.1 资料收集（1-2周）

**工作内容**：
1. 收集区域地质、矿产、构造资料
2. 收集区域航磁、重力数据
3. 整理前人研究成果
4. 建立区域地质资料数据库

#### 1.3.2 区域成矿远景分析（2-4周）

**工作内容**：
1. 分析区域成矿地质背景
2. 解译航磁、重力异常
3. 识别控矿构造与成矿远景区
4. 编制1:50万成矿远景图

#### 1.3.3 成矿带筛选（2-4周）

**筛选标准**：
- 成矿地质条件有利
- 物探异常显著
- 化探异常明显
- 找矿标志齐全

**输出成果**：
- 成矿远景划分图
- 优选成矿带清单
- 草查工作报告

## 第二节 预研阶段操作流程
<!-- WP3-SECTION-STATUS id=A11-stage-2 status=Design-assumption gate=diagnostic-branch+noise-floor -->

### 2.1 阶段目标与定位

**阶段目标**：评估勘查可行性，规划技术方案，编制项目建议书

**阶段定位**：勘查全周期的起点，决定是否投入后续勘查资源的关键决策阶段

**预计工期**：`PENDING/null`；仅在项目工作分解、资源可用性和批准路径冻结后，以计划字段登记，不得作为通用承诺。

**费用接口（Planned）**：明确是否包含数据采集，并按统一币种、基准年和成本时点生成项目级估算；本手册不预设金额区间。

### 2.3 参数设置标准

**先验与噪声合同（Planned）**：先验、误差模型及其超参数必须逐项绑定 `source-id`、单位、支持尺度、适用域和协方差。未绑定字段为 `PENDING/null`，不得进入反演或验收；保留弱信息基线、prior predictive 与 prior-data conflict 检查。

**钻孔资料**：若可用，仅作为层次观测：位置、测量、代表性和尺度转换误差必须显式建模；不得充当物性或界面的硬约束。

**采样方法**：不进行MCMC采样，仅进行确定性分析
- 快速评估方法组合的有效性
- 输出初步的物性分布趋势

### 2.4 标准操作流程

#### 2.4.1 资料收集与整理（1-2周）

**工作内容**：
1. 收集区域地质、矿产、构造资料
   - 收集区域地质图、矿产图、构造纲要图
   - 收集区域地质报告、科研成果报告
   - 建立区域地质资料数据库

2. 收集已有物探数据与报告
   - 重力、航磁、地面电法、电磁法数据
   - 物探解释报告与原始曲线
   - 数据质量评估报告

3. 整理前人研究成果
   - 收集已发表文献
   - 整理勘查历史与工作程度
   - 总结前人认识与存在问题

4. 建立项目数据库
   - 统一坐标系统（建议使用国家2000坐标系）
   - 统一数据格式（建议使用HDF5或NetCDF）
   - 编制数据元数据清单

**输出成果**：
- 区域地质资料数据库（含元数据）
- 物探数据整理报告
- 数据质量初步评估表

**质量检查点**：
- [ ] 数据完整性检查：所有必备数据已收集
- [ ] 元数据完整性检查：每类数据都有完整元数据
- [ ] 坐标系统一致性：所有数据已转换到统一坐标系
- [ ] 格式规范性：所有数据符合标准格式要求

#### 2.4.2 区域成矿分析（2-3周）

**工作内容**：
1. 分析区域成矿地质背景
   - 大地构造位置与演化历史
   - 区域地层、岩浆岩、构造特征
   - 区域成矿系列与成矿系统

2. 识别控矿要素与找矿标志
   - 控矿构造识别（断裂、褶皱、接触带）
   - 控矿地层/岩体识别
   - 地球物理、地球化学找矿标志
   - 遥感找矿标志

3. 总结区域成矿规律与成矿模型
   - 矿床类型与时空分布规律
   - 矿床组合与成矿序列
   - 典型矿床成矿模式

4. 圈定成矿远景区
   - 基于成矿规律定性圈定
   - 划分远景区等级（A类、B类、C类）
   - 编制1:50万成矿远景区图

**输出成果**：
- 区域成矿地质条件分析报告（含相关图件）
- 成矿远景区划分图
- 找矿标志汇总表

**质量检查点**：
- [ ] 成矿规律分析符合区域地质实际
- [ ] 远景区圈定有充分依据
- [ ] 图件比例尺、投影、图例规范
- [ ] 报告逻辑清晰、结论明确

#### 2.4.3 现有数据评估（1-2周）

**工作内容**：
1. 评估已有物探数据质量
   - 数据覆盖范围与密度分析
   - 数据精度与信噪比评估
   - 数据预处理方法检查
   - 数据存在的问题识别

2. 分析数据覆盖范围与精度
   - 绘制数据覆盖范围图
   - 统计测线密度、点距分布
   - 分析探测能力深度范围

3. 识别数据空白区与问题
   - 圈定数据空白区
   - 识别数据质量问题区
   - 分析原因并提出解决方案

4. 制定补充数据采集计划
   - 提出补充采集方法组合
   - 设计补充测线位置
   - 估算补充采集费用

**输出成果**：
- 现有数据质量评估报告
- 数据覆盖范围图
- 补充数据采集建议书

**质量检查点**：
- [ ] 数据评估客观公正、依据充分
- [ ] 问题识别准确、分析到位
- [ ] 补充采集方案合理可行
- [ ] 费用估算给出范围、来源、币种、基准年、成本时点和不确定性

#### 2.4.4 技术方案比选（2-3周）

**工作内容**：
1. 比选不同方法组合方案
   - 基于勘查目标深度选择方法组合
   - 基于地质条件选择方法组合
   - 基于预算约束选择方法组合
   - 分析各方案的探测能力

2. 评估各方案技术可行性
   - 方法组合的理论可行性
   - 仪器设备的可获得性
   - 技术队伍的能力匹配
   - 施工条件的可行性

3. 估算各方案成本与工期
   - 数据采集费用估算
   - 数据处理费用估算
   - 反演解释费用估算
   - 总工期估算

4. 按WP4状态—行动—损失合同比较候选技术方案，不预先宣称最优
   - 综合技术、经济、工期因素
   - 分析推荐方案的优势与风险
   - 提出备选方案

**输出成果**：
- 技术方案比选报告
- 方法组合推荐方案
- 成本-工期估算表

**质量检查点**：
- [ ] 方案比选全面、无遗漏
- [ ] 技术评估科学合理
- [ ] 成本估算有依据
- [ ] 推荐方案理由充分

#### 2.4.5 编制立项建议书（1-2周）

**工作内容**：
1. 撰写地质背景与成矿条件
2. 阐述技术方案与工作部署
3. 编制预算与进度计划
4. 进行风险分析与应对措施

**输出成果**：
- 项目立项建议书
- 预算明细表
- 进度计划甘特图

**质量检查点**：
- [ ] 立项依据充分、论证严密
- [ ] 技术路线清晰可行
- [ ] 预算合理、进度安排可行
- [ ] 风险识别全面、应对措施有效

### 2.6 决策准则

**候选行动比较（不设通用收益成本门）**：
- 成矿条件有利，有明确的成矿远景区
- 技术方案可行，方法组合合理
- 由WP4状态—行动—损失合同比较，须绑定统一币种、基准年、校准概率和成本时点

**调整标准**：
- 成矿条件中等或技术方案需优化
- 需补充调研或调整技术方案

**不通过标准**：
- 成矿条件不利或技术不可行

> **表3.2状态与scope：Design-assumption / A11-REGIONAL-SURVEY-DESIGN。** 下列间距仅为候选初值，不是验收标准；必须根据真实目标尺度、地形、装置、物性对比、噪声、预算及先导数据DOI/EIG重设计。

### 3.3 参数设置标准

**先验类型**：弱约束（一级先验）
- 物性参数采用±30%变化范围
- 引入区域地质规律作为软约束
- 不使用钻孔数据约束

**噪声模型**：高斯分布，$\sigma$由数据质量评估确定
- 重力：$\sigma$ = 5% + 仪器噪声
- 磁法：$\sigma$ = 10% + 仪器噪声
- MT：$\sigma$ = 15% + 仪器噪声

**采样方法**：变分推断（快速）
- 后验分布采用高斯近似
- 计算效率高，适合大范围普查

#### 3.4.4 初步解释流程

**数据处理流程**：
1. 数据预处理
   - 重力：零点漂移改正、固体潮改正、正常场改正、地形改正
   - 磁法：日变、正常场和地形处理；仅当诱导磁化占主导、磁化方向可信且低磁纬稳定性门通过时RTP，否则转矢量/总磁化强度或等效源分支并显式建模剩磁

2. 单方法反演
   - 重力：三维密度反演
   - 磁法：三维磁化率反演
   - MT：只有维性门确认近二维且strike稳定时执行2D TE/TM；三维、各向异性或strike不稳定时强制3D/张量分支

3. 多方法联合反演
   - 贝叶斯联合反演
   - 输出岩性概率分布

4. 综合解释
   - 地质-地球物理综合分析
   - 圈定找矿靶区
   - 靶区排序

- 不确定性分层清晰（高/中/低区）
- 方法权重分布合理

**地质验证**：
- 地质合理性检查通过
- 已知矿点的高概率覆盖

**输出成果**：
- 成矿远景区概率排序图
- 靶区综合信息卡片
- 详查工作部署建议

## 第四节 详查阶段操作流程
<!-- WP3-SECTION-STATUS id=A11-stage-4 status=Design-assumption gate=RTP+MT-dimensionality+DOI -->

### 4.1 阶段目标与定位

**阶段目标**：查明靶区地质特征，定位矿体空间位置，估算资源潜力

**阶段定位**：从靶区优选到矿体定位的关键阶段

**比例尺要求**：1:1万

**预计工期**：12-18个月

**费用接口（Planned）**：按冻结范围和成本口径形成项目级估算，不预设金额区间。

### 4.2 输入数据要求

> **表4.2状态与scope：Design-assumption / A11-TARGET-SURVEY-DESIGN。** 点线距和覆盖范围须按目标尺度、装置、背景物性、噪声、地形及先导DOI/EIG优化；表内数值只是候选初值。

### 4.3 参数设置标准

**先验类型**：中约束（二级先验）
- 物性参数采用±20%变化范围
- 引入区域地质规律作为约束
- 使用已有钻孔数据作为软约束

**噪声模型**：学生t分布（$\nu=5$）
- 更好地处理异常值
- 对重尾分布更稳健

**采样方法**：GPU并行SMC（序列蒙特卡洛）
- 计算效率与精度平衡
- 适合中等维度的联合反演

### 4.4 标准操作流程

#### 4.4.1 详细测量设计（2-4周）

**测网设计原则**：
- 测线方向垂直或斜交主要构造走向
- 测网密度满足探测目标分辨率要求
- 充分利用已有钻孔位置

**方法组合优化**：深度区间只作设计假设。方法参与及权重由本次几何、频时参数、绝对噪声地板、灵敏度/分辨率和后验DOI决定。

#### 4.4.2 高精度数据采集（6-12个月）

**DC/IP测量规范**：
> `Design-assumption / A11-TARGET-SURVEY-DESIGN`：装置、极距、电流和精度须按接地条件、噪声、目标尺度与独立重复观测校准。

**TEM测量规范**：
> `Design-assumption / A11-TARGET-SURVEY-DESIGN`：线框、电流、叠加和精度须按装置响应、背景物性、噪声、目标时窗与DOI校准。

**CSAMT测量规范**：
> `Design-assumption / A11-TARGET-SURVEY-DESIGN`：收发距、频带、电流与精度须满足有限源场区、维性、噪声和DOI验证。

#### 4.4.3 多方法数据融合

**融合策略**：
1. 浅部DC/IP反演 → 提供浅部精细结构
2. 中深部CSAMT反演 → 提供中深部电阻率结构
3. TEM过渡约束 → 衔接浅部与中深部
4. 重磁区域约束 → 提供区域构造格架
5. 多方法联合反演 → 综合所有信息
6. 岩性概率反演 → 输出地质解释结果

**融合流程图**：

#### 4.4.4 三维建模流程

**模型构建步骤**：
1. 建立三维网格
   - 网格尺寸：水平20-50m，垂向10-20m
   - 网格范围：覆盖所有异常区
   - 地形跟随：地表节点按实际地形调整

2. 物性参数建模
   - 密度三维模型
   - 磁化率三维模型
   - 电阻率三维模型
   - 极化率三维模型

3. 岩性概率建模
   - 贝叶斯岩性分类
   - 概率立方体生成
   - 不确定性量化

#### 4.4.5 钻孔位优化

**钻孔位候选行动合同**：预注册不行动、补测和钻探轨迹；对每条轨迹定义见矿事件与空间支持，使用校准概率、施工可行性、成本和损失比较后验期望效用。不得以固定概率/标准差门、通用信息增益最大化或固定加权分数直接选孔。

### 4.5 验证标准

**技术验证**：

- 钻孔结果按预注册事件定义报告并做留出预测校准；不设置无样本合同的符合率门
- 采样诊断只读取WP2联合hard gates，不在手册复制或放宽数值门

**地质验证**：
- 钻孔验证见矿
- 地质解释合理

**输出成果**：
- 靶区三维岩性概率模型
- 钻孔位建议图
- 资源潜力估算报告

## 第五节 勘探阶段操作流程

### 5.1 阶段目标与定位

**阶段目标**：精确控制矿体形态并形成靶体潜力情景；正式资源量须经独立合规评价后方可为矿山建设提供依据

**阶段定位**：勘查与开发衔接的关键阶段

**比例尺要求**：1:2000

**预计工期**：18-36个月

**费用接口（Planned）**：按冻结范围和成本口径形成项目级估算，不预设金额区间。

### 5.2 输入数据要求

> **表5.2状态与scope：Design-assumption / A11-DEEP-SURVEY-DESIGN。** 三维测网与点距须按目标尺度、装置、背景物性、噪声、井旁效应和后验DOI/EIG逐项目确定；下列范围不是固定能力或验收门。

### 5.3 参数设置标准

**先验与钻孔观测接口（Planned）**：先验族、强度、物性不确定性和结构耦合均须由项目 manifest 预注册，并以 prior predictive、竞争基线和隔离评价校准；不设固定百分比变化范围。钻孔岩性、测井、取样和井中物探是带位置、测量、代表性、支持体积与尺度转换误差的条件观测，不能将对应网格固定为无误差硬值；其 source-id 必须只进入声明的层次观测入口，评价孔与训练/先验来源保持祖先集合互斥。

**采样方法（Planned接口）**：候选RJMCMC与并行回火；每个 Green move 必须记录 Jacobian、forward density（q_forward）与 reverse density（q_reverse），并满足 WP2 生产 draw 冻结合同后方可用于定量输出。
- 链数由预注册诊断设计确定，不以“至少5条”替代独立重复与联合硬门
- 并行回火用于候选模态探索，不预设加速
- 自适应提议必须满足适应性条件并在冻结生产阶段停止或按合同控制

### 5.4 标准操作流程

#### 5.4.1 深部探测设计

**三维测网设计**：
- 测线间距：50-100m
- 测点间距：50m
- 测线方向：垂直构造走向

**方法组合**：
- 核心方法：WFEM/CSAMT
- 约束方法：MT、重磁
- 校验方法：钻孔、井中物探

#### 5.4.2 精细反演流程

**反演策略**：
1. 分层反演
   - 浅部：基于钻孔约束的确定性反演
   - 中部：贝叶斯联合反演
   - 深部：重磁约束下的贝叶斯反演

2. 迭代优化
   - 初始反演 → 地质解释 → 先验更新 → 重新反演
   - 通常需要2-3轮迭代

3. 不确定性量化
   - 后验统计
   - 敏感性分析

**钻孔设计原则**：
1. 控制矿体边界
2. 验证高概率靶区
3. 估计靶体体积/潜力情景（非正式资源量）
4. 研究矿体特征

**钻孔布置方案**：

#### 5.4.4 靶体体积/潜力情景

**物探情景方法**：
1. 基于概率立方体的积分法
2. 克里格法作为对比
3. P10/P50/P90三种情景

**合规边界**：P10/P50/P90仅表示靶体体积/潜力情景，不映射为探明、控制或推断资源量。正式分类须按适用法规/标准，联合钻孔品位、体积密度、支持尺度、合理开采前景并由合资格人员签署。

#### 5.4.5 勘探报告编制

**报告内容要求**：

3. 数据处理与反演解释
4. 矿体特征与靶体潜力情景；正式资源量引用独立合规报告
5. 开发利用建议

### 5.5 验证标准

**技术验证**：
- `calibration_type=holdout_predictive_calibration`联合报告名义水平、留出预测区间覆盖、宽度/锐度及PIT/rank；PPC另作模型检查
