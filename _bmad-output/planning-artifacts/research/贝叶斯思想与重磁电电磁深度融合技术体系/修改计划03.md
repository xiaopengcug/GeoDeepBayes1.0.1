# 《审查意见03》修改计划

制定日期：2026-07-17  
依据：《审查意见03.md》  
计划性质：重大整改与技术路线纠偏计划  
适用对象：研究文稿、附录、工程代码、契约、证据登记、验证运行包与CI  

## 一、计划目标

本轮修改不以“逐条增加修订注”为完成标准，而以以下结果为目标：

1. 消除《审查意见03》全部P0理论、概率、物理和决策公式错误。
2. 使正文中的每项能力主张与当前代码、契约和证据等级一致。
3. 建立可执行的观测契约、诊断合同、运行清单和CI门禁。
4. 重新生成可复算的小型重磁证据，纠正DO-27正则化选择和synthetic-block证据不完整问题。
5. 形成有针对性的物理、离散化、概率校准、代理误差和公平基准测试方案。
6. 在完成至少一个重磁联合案例和一个DC/EM最小案例前，不宣称“全方法闭环”。
7. 形成《整改落实报告03》和四专项复审材料，使复审人员可以逐项判定通过、部分通过或未通过。

## 二、变更范围与策略

### 2.1 范围定级

本次属于**重大变更**，影响：

- 理论总纲：联合概率模型、似然、先验、降维测度、RJMCMC、信息增益。
- 价值决策：资源量情景、风险、ENPV及现场评价指标。
- 地球物理：TEM、CSAMT、WFEM、物性温压模型、深度与分辨率表述。
- 工程架构：算子能力、伪代码边界、CI、契约、运行证据和TRL。
- 实验设计：解析回归、离散化、SBC/PPC、对抗场景、公平基准和盲测。
- 证据治理：Planned/Synthetic-run/Field-validated状态、Evidence ID和Observed列。

### 2.2 推荐路径

采用“**范围降级 + 直接修正 + 分阶段补证据**”的混合路径：

1. 保留已经验证的重力、磁法、诊断和小型采样模块，不回滚代码。
2. 将当前产品/文稿定位降为“理论草案、局部重磁原型与验证计划”。
3. 先完成P0理论和物理修订，再修改代码与契约；禁止用代码实现反向掩盖公式缺陷。
4. 电法/电磁法按“观测契约→解析回归→最小算子→梯度/离散化测试→联合案例”顺序推进。
5. 大规模GPU、完整PGI、RJMCMC、VI、现场矿区和产业化结果不纳入本轮最低放行范围，保留为后续里程碑。

### 2.3 暂缓事项

以下内容本轮只做诚实降级，不承诺实现：

- 百万网格、多GPU和分布式生产平台。
- 完整五方法联合反演。
- 完整PGI历史环境复现。
- 高维RJMCMC、并行回火和VI生产实现。
- Field-validated矿区结论、命中率和财务收益。
- 正式资源量、可采资源量和商业投资承诺。

## 三、执行原则

1. **公式先于代码**：每个P0公式先形成定义、适用条件和独立复核记录，再进入实现。
2. **证据不外推**：单物理不支持联合，多峰小例不支持高维，求解器停止不等于模型有效。
3. **一项主张一个证据锚点**：性能表、结论和摘要均绑定Evidence ID。
4. **Planned不填结果**：未运行项目的Observed列保持空值，不再填“预估结果式数字”。
5. **失败也是证据**：运行失败、超时、不收敛和校准不合格必须保留在运行包中。
6. **四眼复核**：理论/物理公式由作者之外的相应专家复核；代码和证据由不同责任人复核。
7. **不以修订注代替整改**：错误主表、公式和正文必须直接修改，修订注只记录变更原因。

### WP8：对抗性实验与验证设计

责任角色：地球物理、UQ、算法、QA联合负责。

任务组：
