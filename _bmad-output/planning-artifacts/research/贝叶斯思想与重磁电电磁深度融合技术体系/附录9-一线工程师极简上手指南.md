## 9.2 五项关键检查（扩展版）

反演完成后，必须完成以下五项关键检查，确保结果可靠可用。

### 9.2.1 数据质量检查

**检查目的**：确保输入数据满足反演要求，避免"垃圾进、垃圾出"。

| 检查项 | 检查内容 | 合格标准 | 处置方式 |
|--------|----------|----------|----------|
| **完整性检查** | 数据覆盖率 | 目标区域覆盖率>80% | 补充测线或缩小研究区 |
| | 测点分布 | 测点分布均匀，无明显空白区 | 补充测量或标记空白区 |
| **精度检查** | 重复测量误差 | 相对误差<5% | 重新测量或标记可疑点 |
| | 仪器一致性 | 多台仪器相对偏差<3% | 仪器校准或数据归一化 |
| **噪声检查** | 信噪比 | 主频信噪比>10dB | 数据去噪或剔除高噪点 |
| | 异常值比例 | 异常值比例<5% | 剔除或单独处理异常值 |
| **一致性检查** | 不同方法空间位置 | 测点位置重合度>90% | 空间插值或位置校正 |
| | 不同方法时间一致性 | 同期测量或季节校正 | 时间归一化处理 |

**快速检查命令**：
```bash
# 数据质量自动检查
./data_check.sh input_data/ --output=quality_report.txt

# 输出示例：
# 数据完整性: ✓ 92% 覆盖
# 测点分布: ✓ 均匀
# 信噪比评估: ✓ 平均 15dB
# 异常值检测: ⚠ 发现 3.2% 异常点
# 建议: 剔除异常点后继续
```

### 9.2.2 先验合理性检查

**检查目的**：确保先验假设与工区地质实际相符，避免先验偏差误导结果。

| 检查项 | 检查内容 | 合格标准 | 处置方式 |
|--------|----------|----------|----------|
| **物性范围检查** | 密度范围 | 与区域岩石密度统计一致 | 调整先验范围或分区域设置 |
| | 磁化率范围 | 与区域岩石磁性统计一致 | 调整先验范围或分区域设置 |
| | 电阻率范围 | 与区域电性统计一致 | 调整先验范围或分区域设置 |
| **地质结构检查** | 已知构造位置 | 做prior-data conflict诊断 | 不看当前反演结果调先验；比较预声明基础先验与robust mixture prior |
| | 已知地层界线 | 核查独立数据来源与支持尺度 | 仅用独立训练资料更新超先验版本 |
| **成矿规律检查** | 控矿要素 | 做先验预测与冲突诊断 | 报告决策量对预声明超先验的敏感性 |
| | 矿化特征 | 已知矿化区有相应异常响应 | 验证方法有效性 |

**先验预测检验（PPC）**：
```python
# 先验预测检验伪代码
prior_samples = sample_from_prior(N=1000)
prior_predictions = forward_model(prior_samples)
if prior_predictions overlaps_observed_data:
    print("先验设置合理 ✓")
else:
    print("先验可能过严或过松，建议调整")
```

### 9.2.3 收敛性检查

**检查目的**：确保MCMC采样充分收敛，后验估计可靠。

| 检查指标 | 计算方法 | 合格标准 | 说明 |
|----------|----------|----------|------|
| **rank-normalized split-Rhat** | 按唯一诊断合同实现 | 读取合同并联合判断 | 不复制阈值 |
| **bulk/tail ESS** | 按唯一诊断合同实现 | 读取合同并联合判断 | 不得用总ESS单指标放行 |
| **关键决策量MCSE** | 按唯一诊断合同实现 | 读取合同并联合判断 | 与Rhat、bulk/tail ESS、模态访问和失败率共同判定 |
| **踪迹图检查** | 目视检查 | 无趋势、良好混合 | 辅助判断 |

**收敛诊断示例**：
```
========================================
收敛性诊断报告
========================================
run_id   diagnostic_contract                         joint_gate_status
----------------------------------------------------------------------
<填写>   validation/wp2-toy/diagnostic-contract.json <Passed|Failed>
----------------------------------------------------------------------
整体判断: 仅使用合同联合门状态
建议: Failed时保留失败链并按预注册方案增加预算或改进采样器
========================================
```

### 9.2.4 地质一致性检查

**检查目的**：确保反演结果与区域地质认识不矛盾，具备地质合理性。

| 检查项 | 检查内容 | 判断标准 | 处置方式 |
|--------|----------|----------|----------|
| **构造一致性** | 断裂位置 | 反演断裂与已知断裂位置偏差<100m | 可接受 |
| | 构造走向 | 反演走向与区域构造线一致 | 可接受 |
| **地层一致性** | 地层界面 | 反演界面深度偏差<15% | 可接受 |
| | 岩性分布 | 反演岩性与区域岩性分布规律一致 | 可接受 |
| **成矿一致性** | 矿化空间 | 反演高概率区与已知矿化空间关系合理 | 专家判断 |
| | 控矿要素 | 反演结果体现已知控矿要素 | 专家判断 |
| **钻孔一致性** | 钻孔验证 | 钻孔揭露岩性与反演概率相符 | 符合率>70% |

**地质一致性评分表**：

| 评分项 | 权重 | 评分标准 | 得分 |
|--------|------|----------|------|
| 构造吻合度 | 30% | 完全吻合(100分) / 基本吻合(70分) / 存在偏差(40分) | __ |
| 地层吻合度 | 25% | 完全吻合(100分) / 基本吻合(70分) / 存在偏差(40分) | __ |
| 钻孔符合率 | 30% | >90%(100分) / 70-90%(70分) / <70%(40分) | __ |
| 成矿规律一致性 | 15% | 完全一致(100分) / 基本一致(70分) / 不一致(40分) | __ |

**总分>70分**：通过一致性检查<br>
**总分50-70分**：需要解释差异原因<br>
**总分<50分**：需重新审视先验或数据质量

### 9.2.5 结果可靠性检查

**检查目的**：综合评估反演结果的可靠性和实用性。

| 检查维度 | 评估指标 | 评估标准 |
|----------|----------|----------|
| **不确定性合理性** | 高概率区与低不确定性对应 | >80%高概率区具有低不确定性 |
| | 不确定性分层清晰 | 高/中/低不确定区界限分明 |
| **预测能力** | 交叉验证准确率 | 留一法验证准确率>75% |
| | 钻孔验证符合率 | 已有钻孔符合率>70% |
| **稳定性** | 参数扰动稳定性 | 参数±10%扰动，结果变化<15% |
| | 随机种子稳定性 | 不同随机种子结果基本一致 |
| **实用性** | 靶区可区分性 | 高/中/低概率靶区界限明确 |
| | 决策支撑价值 | 可有效支撑钻探部署决策 |

**可靠性综合评级**：

| 等级 | 标准 | 建议 |
|------|------|------|
| **A级（优秀）** | 五项检查全部通过，各项指标优秀 | 可直接用于钻探部署 |
| **B级（良好）** | 五项检查通过，部分指标中等 | 可用于钻探部署，需谨慎解释 |
| **C级（合格）** | 五项检查基本通过，存在少量问题 | 建议补充数据后重新反演 |
| **D级（不合格）** | 多项检查未通过 | 需诊断问题后重新处理 |

- 不同方法数据必须统一轴序、水平/垂向基准、单位和z正方向，并记录转换误差

```python
# 坐标转换示例

# 转换到目标坐标系统
data = utils.reproject_coords(
    data,
    from_epsg=4326,  # WGS84
    to_epsg=32650    # UTM Zone 50N
```

### 9.3.3 收敛问题

**Q6: 反演不收敛怎么办？**

按以下顺序排查：

```
问题诊断流程：
│
├─ 1. 检查迭代次数是否足够？
│     → 增加 max_iterations 参数（默认20000）
│
├─ 2. 检查提议分布是否合适？
│     → 使用自适应提议分布（adaptive_proposal=True）
│
├─ 3. 检查模型维度是否过高？
│     → 启用POD降维（enable_pod=True）
│
├─ 4. 检查是否存在多峰分布？
│     → 增加马尔可夫链数量（n_chains=8）
│     → 启用并行回火（parallel_tempering=True）
│
└─ 5. 检查数据与模型是否匹配？
      → 验证正演算子精度
      → 检查数据预处理质量
```

**Q8: 概率值多少才算高概率靶区？**

分级标准：

| 概率范围 | 分级 | 钻探建议 |
|----------|------|----------|
| P > 0.75 | 高概率靶区 | 优先钻探验证 |
| 0.5 < P ≤ 0.75 | 中概率靶区 | 补充验证后考虑 |
| 0.25 < P ≤ 0.5 | 低概率靶区 | 待进一步验证 |
| P ≤ 0.25 | 极低概率区 | 不建议钻探 |

**Q9: 如何判断不确定性是否合理？**

不确定性合理性判断：

| 不确定性级别 | 标准差范围 | 可信度 |
|--------------|------------|--------|
| 低不确定性 | σ < 0.1 | 高 |
| 中等不确定性 | 0.1 ≤ σ < 0.2 | 中 |
| 高不确定性 | σ ≥ 0.2 | 低 |

**理想情况**：高概率区对应低不确定性，低概率区对应高不确定性。

**Q10: 结果与地质认识不符怎么办？**

排查顺序：

1. **验证数据质量**：检查是否存在系统性偏差
2. **验证先验设置**：确认先验假设与区域地质一致
3. **验证正演精度**：检查正演算子是否考虑地形等因素
4. **考虑多解性**：地球物理反演本质是非唯一的
5. **专家会诊**：组织地质、物探专家联合解释
