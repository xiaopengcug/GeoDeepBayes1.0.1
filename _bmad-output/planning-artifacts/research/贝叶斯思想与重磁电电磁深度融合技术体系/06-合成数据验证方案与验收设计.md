## 六、合成数据验证方案与验收设计（含对抗性测试）

> **验证边界。** 本章是参考回归和预注册验收设计；PPC仅以观测discrepancy相对后验预测复制分布的位置、尾部失配和校准图实施模型检查，不是SBC、参数覆盖或留出预测覆盖。深度、频率、点距、网格和噪声均为带装置/物性/DOI作用域的Design-assumption。示例代码为不可执行伪代码，除非绑定源码、测试与manifest。

> **证据状态：Planned。** 本章是预注册验证方案，不包含实际运行结果，也不提供t值、p值、效应量、覆盖率或命中率基线。只有附带代码版本、配置、随机种子、原始输出和可复算脚本的运行方可标为Synthetic-run。

> **WP3物理验证总门。** 本章所有“覆盖深度、极限深度、网格、频率、点距和噪声百分比”均为`Design assumption`，不是方法能力或Observed。每个EM数据集必须保存源—接收几何、复数/时间约定、原始观测单位、绝对噪声地板与相对误差、协方差、网格/时步/边界收敛以及灵敏度/分辨率或后验DOI。合成噪声施加在冻结的复分量或TEM时窗电压上。

### 6.1 基础合成模型与观测数据
<!-- WP3-SECTION-STATUS id=06-6.1 status=Design-assumption gate=reference-regression+noise-floor+DOI -->

**真实地质模型**：三维斑岩型铜矿模型，范围4000m×4000m×6000m，网格尺寸50m×50m×50m，总网格数384000。模型包含3类岩性：背景花岗岩、热液蚀变带、中心斑岩铜矿体（筒状展布，中心埋深2500m，垂向延伸2000m，水平直径500m），具备“低阻-高极化-中高密度”的物性特征。

**观测数据**：

1. 重磁数据：50m×50m网格地面观测。噪声作用于冻结单位的原始分量，采用
   $\Sigma_{\rm GM}=D R D$，$D_{ii}^2=(r|s_i|)^2+a_i^2$；$R$为预先给定并经SPD检查的空间/分量相关矩阵，$a_i>0$为绝对噪声地板。不得在近零值或符号变化异常上直接使用“百分比高斯噪声”；若需截断或仪器饱和，须在生成模型中显式登记截断界和归一化常数；

2. DC/IP数据：100m×100m候选地面测网，0—1500 m仅为合成建模域候选，不是覆盖能力；有效信息深度由装置、物性对比、绝对噪声地板、灵敏度/分辨率和后验DOI共同判定。视电阻率与视极化率噪声参数须在生成合同中登记相对项、绝对地板及相关结构；

3. CSAMT数据：20条测线；1000-3000m仅为设计目标，由有限源灵敏度/DOI验收；复分量使用相对误差加绝对噪声地板；

4. WFEM数据：100m×100m设计测网；1000-3000m为设计目标，不声明固定极限；复$\Delta U/I$使用相对误差加绝对噪声地板；

5. MT数据：200m×200m设计网格；深度由维性、频带、噪声及DOI验收，复阻抗使用结构协方差；

6. 2个验证钻孔，位于矿体边缘，提供硬数据约束。

**多场景统计重复设计**：统计推断的独立单位是从预注册场景生成分布独立抽取的地质场景；同一场景下的多个噪声实现是嵌套重复，算法随机种子只是同一“场景—数据集—方法”单元的数值重复，均不得扩充独立样本量。场景数不预填为3—5，而由主要终点的最小实际重要差异、场景间方差和预注册检验/层次模型经功效分析或simulation-based calibration确定，并报告假设与敏感性。

### 6.3 基础场景验收设计
<!-- WP3-SECTION-STATUS id=06-6.3 status=Design-assumption gate=reference-regression+uncertainty -->

#### 6.3.1 定量验证指标

为评估候选体系的不同性质，以下给出预注册的多维度定量验证指标设计：

|指标类别|指标名称|计算公式|目标值|验证方法|
|---|---|---|---|---|
|精度指标|NRMSE|$\sqrt{n^{-1}\sum_i(\hat y_i-y_i)^2}/s_y$|不设通用门；按任务预注册最小实际重要差异|$s_y>0$的冻结尺度（如真值范围或训练集标准差）|
|精度指标|MAPE（受限）|$100n^{-1}\sum_i|\hat y_i-y_i|/\max(|y_i|,\epsilon_{\rm scale})$|不设通用门|仅用于真值远离零的正值量；报告$\epsilon_{\rm scale}$与敏感性|
|参数校准|SBC rank|独立参数—数据重复中的随机化rank|不设通用通过门；报告有限样本均匀性诊断|算法校准诊断|
|参数校准|经验区间覆盖|预注册功能量的可信区间命中指示之场景级均值|与名义水平并列报告差值和区间|参数推断校准|
|模型检查|PPC discrepancy位置与校准图|观测discrepancy在后验预测复制分布中的位置、单双侧尾部失配及按预注册分组绘制的观测—复制校准图|不设通过门|后验预测检查|
|概率指标|CRPS|$\int_{-\infty}^{\infty}[F(z)-\mathbf 1\{y\le z\}]^2\,dz$|不设通用门；按配对差与实际重要差异报告|连续概率评分|
|结构指标|SSIM（可选）|$(2\mu_x\mu_y+c_1)(2\sigma_{xy}+c_2)/[(\mu_x^2+\mu_y^2+c_1)(\sigma_x^2+\sigma_y^2+c_2)]$|不设通用门|仅在网格、窗口、动态范围及$c_1,c_2$均预注册时报告|

**指标说明**：

- **NRMSE（归一化均方根误差）**：RMSE保留原始物性单位；只有除以预注册且严格为正的尺度$s_y$后才报告无量纲NRMSE，不把有量纲RMSE与百分比阈值比较
- **MAPE（平均绝对百分比误差）**：仅在真值远离零且预先给定尺度阈值时使用，分母采用$\max(|y_i|,\epsilon_{\rm scale})$并报告$\epsilon_{\rm scale}$；含零或近零真值时改用MAE、归一化RMSE或sMAPE
- **SBC rank合同**：SBC算法校准使用独立生成重复数 \(R_{\mathrm{SBC}}\)。对每个重复 \(r\)，从生成先验抽取真值 \(\theta_r\)、生成数据并取得固定数量 \(L\) 个后验draw。令 \(a_r=\sum_{\ell=1}^{L}\mathbf1\{\theta_{r\ell}<\theta_r\}\)、\(t_r=\sum_{\ell=1}^{L}\mathbf1\{\theta_{r\ell}=\theta_r\}\)，并由预注册随机种子独立生成 \(U_r\sim\operatorname{DiscreteUniform}\{0,1,\ldots,t_r\}\)，保存随机化rank \(R_r=a_r+U_r\in\{0,1,\ldots,L\}\)；当 \(t_r=0\) 时 \(U_r=0\)。冻结参数/功能量清单、相等判定规则、\(L\)、\(R_{\mathrm{SBC}}\)、分箱或ECDF方法及有限样本检验；报告rank图、偏差/过散/欠散诊断、Monte Carlo区间和失败率，不以单个p值设通用通过门。\(R_{\mathrm{SBC}}\) 仅控制算法校准的Monte Carlo精度，不得替代方法比较的独立地质场景数 \(N_{\mathrm{power}}\)；后者由主要终点的功效设计确定。
- **经验区间覆盖合同**：覆盖率与SBC rank分开计算。对预注册功能量 \(g_k(\theta)\) 和名义水平 \(q\)，每个独立地质场景只贡献一个区间命中指示；分母是所有预注册场景，异常退出、非有限后验或缺区间均按失败记为未命中且不得重抽。报告命中数/总数、与名义水平之差、Wilson或预注册层次区间、容差及其科学理由；噪声实现和算法种子不得扩充分母。
- **后验预测检查（PPC）**：在解封前冻结观测discrepancy \(T(y_{\mathrm{obs}},\theta)\)、复制discrepancy \(T(y^{\mathrm{rep}},\theta)\)、观测分组/空间支持、复制机制和图形摘要；报告 \(T(y_{\mathrm{obs}},\theta)\) 在 \(T(y^{\mathrm{rep}},\theta)\) 后验预测复制分布中的位置、预注册单双侧尾部概率、中心/尾部/空间相关/跨方法残差失配及按组校准图。不得以复制样本落入其自身复制包络的频率作为PPC指标。PPC用于定位模型失配，不设统一“通过”门，也不解释为参数真值覆盖率。
- **靶区概率校准**：使用reliability diagram、Brier score和对数评分，同时报告校准与锐度
- **CRPS比较合同**：对同一独立地质场景、同一留出观测功能量与同一预测时点，比较候选预测CDF和冻结基线CDF；先在场景内汇总嵌套噪声/种子，再形成场景级配对CRPS差。预注册“越小越好”的方向、最小实际重要差异、失败/缺测处理和区间估计；报告原量纲CRPS、配对差及区间，不以“最小”或单次点估计宣告优胜。
- **SSIM（结构相似性指数）**：只作任务特定的辅助终点，不设跨物理量通用阈值；必须同时报告窗口、动态范围与稳定常数

#### 6.3.2 统计显著性检验框架

为检验候选体系相对于冻结基线的差异，以下给出预注册假设检验框架：

**估计目标与方向**：对每个独立地质场景，在同一冻结数据集上计算候选方法与基线的配对差$\Delta_j$；指标方向在预注册表中统一为“越大越好”或“越小越好”。主要问题是估计$\Delta$及其区间并与最小实际重要差异$\delta_{\rm MID}$比较，不预设本体系优胜，也不把未达到显著性解释为等效。

```text
estimand: scene-level paired difference
decision: compare interval with preregistered delta_MID
direction: frozen before truth unblinding
```

**层次与配对分析**：以场景为最高层独立单位；噪声实现嵌套于场景，算法种子嵌套于“场景—噪声—方法”。优先拟合含场景随机效应的配对层次模型，或先在场景内汇总再对场景级配对差做稳健区间估计。若使用配对t或置换/符号秩检验，适用条件、缺失/失败处理和交换性假设必须在解封前冻结。

```text
independent_unit: geological_scene
nested_repeats: noise_realization, algorithm_seed
```

**效应量**：连续终点报告场景级平均配对差及其区间；需要标准化时使用配对差标准差$d_z=\bar\Delta/s_\Delta$，同时保留原量纲差与$\delta_{\rm MID}$。不使用独立组的pooled SD，也不套用0.2/0.5/0.8通用标签。二元失败率使用配对风险差/风险比及区间。

**多重性**：在解封前区分一个主要终点、关键次要终点与探索性终点；为确认性终点预注册层级检验、Holm或其他与问题匹配的族错误率/FDR策略，并明确检验族。Bonferroni不是固定默认。所有估计量与区间均报告，不以校正后$p$值替代效应大小。

```text
multiplicity: preregister family and procedure
report: effects, intervals, failures
```

#### 6.3.3 基础场景预注册比较

在相同数据、网格、误差预算和随机预算下，至少比较：①多方法条件独立但不耦合（$\lambda=0$）；②空间掩膜下的软结构耦合；③岩石物理耦合；可另列单方法作为诊断基线。三种核心模型分别报告留出预测、SBC算法校准检查、PPC模型检查、锐度、失败率和计算成本，不把其中任何一种预设为优胜。最高层统计重复单位是独立抽取的**地质场景**；噪声实现与算法种子按6.1所述嵌套，不是额外独立样本，同一场景中的网格或钻孔也不是独立重复。预先固定主要终点、$\delta_{\rm MID}$、层次结构、多重比较策略、失败处理和停止规则；场景数与每层重复数由功效分析或模拟校准确定，运行前不填写t、p或效应量。

虚拟钻孔评价从每个联合后验样本逐个判断钻孔轨迹是否同时满足最小矿化厚度、连续性与品位阈值，再以事件频率估计成功概率。禁止把同一空间场中的1000个孔视为1000个独立样本，采用按独立场景汇总的层次模型或区块bootstrap。

### 6.4 对抗性场景1：弱物性差异隐伏矿体测试
<!-- WP3-SECTION-STATUS id=06-6.4 status=Design-assumption gate=held-out-detection+competing-explanations -->

**测试场景设置**：将矿体与围岩的物性差异缩小80%，矿体电阻率仅比围岩低15%，极化率仅高10%，密度、磁化率差异均小于5%，模拟传统方法无法识别的弱异常隐伏矿体。

**Planned验收**：按6.3.3的独立重复设计比较各方案，不预填结果。弱异常的物性对比、噪声和目标尺度在运行前冻结，并报告失败案例。

结果表在实际运行前保持为空；结果schema包括点估计、区间、场景层级效应、随机种子和失败计数。

**分析计划**：比较识别失败率、重合度、边界距离、概率校准和计算成本，并按场景报告区间与失败案例；不得在运行前写入方向性结论。

### 6.5 对抗性场景2：厚低阻覆盖层强干扰测试
<!-- WP3-SECTION-STATUS id=06-6.5 status=Design-assumption gate=noise-floor+DOI+competing-explanations -->

**测试场景设置**：覆盖层厚度、电阻率、横向非均匀性和噪声协方差从预注册的场景生成分布抽取；其范围须由目标区域资料、装置灵敏度及独立来源约束。覆盖层响应与深部目标的可分辨性按频时响应、绝对噪声地板和DOI评价，不把单一厚度、电阻率或信噪比衰减外推为跨区域极端场景。

**Planned验收**：按6.3.3的独立重复设计比较各方案，不预填结果。共享覆盖层误差必须进入联合误差模型，并与错误的条件独立模型进行校准消融。

结果表在实际运行前保持为空；同时报告校准与锐度，不能仅以扩大区间提高覆盖率。

**分析计划**：检查覆盖层nuisance参数的可辨识性、深部预测校准、边界距离和失败率。检验方法依据预注册的残差与场景层级结构选择；偏态时使用适当的稳健/层次方法，不预填Wilcoxon统计量。

### 6.6 工程落地预期方案

#### 示例：深部金矿勘查项目（预期方案）

- 场景范围：在运行清单中预注册，不外推到现场工区

```python
import pytest
import numpy as np
from geodeepbayes.forward import DCForwardSolver

class TestDCForwardSolver:
    """DC正演算子单元测试"""

    @pytest.fixture
    def homogeneous_model(self):
        """均匀半空间模型"""
        return {"resistivity": 100.0}  # 100 Ω·m

    @pytest.fixture
    def electrode_config(self):
        """温纳装置配置"""
        return {
            "array_type": "wenner",
            "a": 50,  # 电极间距50m
            "n_electrodes": 64
        }

    def test_homogeneous_half_space_response(
        self, homogeneous_model, electrode_config
    ):
        """测试均匀半空间响应"""
        solver = DCForwardSolver(electrode_config)
        apparent_resistivity = solver.compute(homogeneous_model)

        # 均匀半空间的视电阻率应等于真电阻率
        np.testing.assert_allclose(
            apparent_resistivity,
            100.0,
            rtol=0.01,
            err_msg="均匀半空间视电阻率计算错误"
        )

    def test_jacobian_directional_derivative(self, homogeneous_model, electrode_config):
        """以同一参数化和电极极性检验方向导数，而不假定Jacobian符号。"""
        solver = DCForwardSolver(electrode_config)
        jacobian = solver.compute_jacobian(homogeneous_model)
        direction = registered_nonzero_direction(homogeneous_model)
        h = registered_finite_difference_step(homogeneous_model, direction)
        f_plus = solver.compute(perturb(homogeneous_model, h * direction))
        f_minus = solver.compute(perturb(homogeneous_model, -h * direction))
        fd = (f_plus - f_minus) / (2 * h)
        np.testing.assert_allclose(jacobian @ direction, fd, rtol=registered_tolerance())
        # 参数化、接收极性和单位进入测试manifest；符号随其改变而可能改变。

    def test_reciprocity_principle(self, electrode_config):
        """测试互易定理"""
        # 互换供电与测量电极，结果应相同
        model = {"resistivity": 50.0}
        solver = DCForwardSolver(electrode_config)

        # 正向测量
        v1 = solver.compute(model)

        # 互换电极后测量
        swapped_config = electrode_config.copy()
        swapped_config["reciprocal"] = True
        solver_swapped = DCForwardSolver(swapped_config)
        v2 = solver_swapped.compute(model)

        np.testing.assert_allclose(v1, v2, rtol=0.001)
```

```python
import pytest
import numpy as np
from geodeepbayes.sampling import MetropolisHastings, ParallelTempering

class TestMetropolisHastings:
    """Metropolis-Hastings采样器单元测试"""

    @pytest.fixture
    def gaussian_target(self):
        """高斯目标分布"""
        return {
            "mean": np.array([0.0, 0.0]),
            "cov": np.array([[1.0, 0.5], [0.5, 1.0]])
        }

    def test_sampling_shape(self, gaussian_target):
        """测试采样输出形状"""
        sampler = MetropolisHastings(
            log_prob=lambda x: -0.5 * (x - gaussian_target["mean"]).T @
                           np.linalg.inv(gaussian_target["cov"]) @
                           (x - gaussian_target["mean"]),
            dim=2,
            step_size=0.1
        )

        n_samples = 1000
        samples = sampler.sample(n_samples, warmup=100)

        assert samples.shape == (n_samples, 2), "采样形状不正确"

    def test_detailed_balance(self, gaussian_target):
        """测试细致平衡条件"""
        sampler = MetropolisHastings(
            log_prob=lambda x: -0.5 * np.sum(x**2),
            dim=1,
            step_size=0.5
        )

        # 运行足够长以达到平衡
        samples = sampler.sample(5000, warmup=1000)

        # 样本均值应接近0
        assert abs(np.mean(samples)) < 0.1, "样本均值偏离目标分布"

    def test_acceptance_rate_reasonable(self, gaussian_target):
        """测试接受率在合理范围内"""
        sampler = MetropolisHastings(
            log_prob=lambda x: -0.5 * np.sum(x**2),
            dim=2,
            step_size=0.3
        )

        samples, stats = sampler.sample_with_stats(1000, warmup=100)

        # 接受率应在20%-50%之间
        assert 0.2 < stats["acceptance_rate"] < 0.5, \
            f"接受率{stats['acceptance_rate']:.2%}超出合理范围"
```

```python
import pytest
import numpy as np
from geodeepbayes.prior import CrossGradientPrior, GMMPrior

class TestCrossGradientPrior:
    """交叉梯度先验单元测试"""

    def test_identical_models_zero_penalty(self):
        """测试相同模型无惩罚"""
        prior = CrossGradientPrior(lambda_val=1.0)

        model1 = np.ones((10, 10, 10))
        model2 = np.ones((10, 10, 10))

        penalty = prior.compute(model1, model2)

        # 相同模型的交叉梯度惩罚应为0
        assert penalty == 0.0, "相同模型应有零交叉梯度惩罚"

    def test_gradient_alignment(self):
        """测试梯度对齐效果"""
        prior = CrossGradientPrior(lambda_val=1.0)

        # 创建一个边界清晰的模型
        model1 = np.zeros((10, 10, 10))
        model1[5:, :, :] = 1.0

        model2 = np.zeros((10, 10, 10))
        model2[5:, :, :] = 1.0

        penalty = prior.compute(model1, model2)

        # 边界对齐的模型应有较小惩罚
        assert penalty < 1.0, "边界对齐的模型应有较小惩罚"

class TestGMMPrior:
    """高斯混合模型先验单元测试"""

    @pytest.fixture
    def gmm_params(self):
        """GMM参数"""
        return {
            "means": np.array([[100, 0.05], [1000, 0.02]]),
            "covariances": [np.eye(2) * 10, np.eye(2) * 50],
            "weights": np.array([0.7, 0.3])
        }

    def test_log_prob_computation(self, gmm_params):
        """测试对数概率计算"""
        prior = GMMPrior(gmm_params)

        # 测试点1：接近第一个分量
        test_point1 = np.array([100, 0.05])
        log_prob1 = prior.log_prob(test_point1)

        # 测试点2：远离所有分量
        test_point2 = np.array([5000, 0.2])
        log_prob2 = prior.log_prob(test_point2)

        # 接近分量的点应有更高概率
        assert log_prob1 > log_prob2, "接近分量的点应有更高概率"

    def test_normalization_and_support(self, gmm_params):
        """测试变换空间 GMM 的解析归一化与物理支持域。

        混合正态在整个 R^d 上的积分由非负权重和为一解析保证；不得以
        有界矩形 Monte Carlo 和宽松容差冒充无界归一化证明。电阻率与
        极化率在 log/logit 潜变量空间建模，物理变量只由反变换产生。
        """
        prior = GMMPrior(gmm_params)

        # 验证1：各分量中心 log_prob 为有限值
        for i in range(len(gmm_params["weights"])):
            center = gmm_params["means"][i]
            log_p = prior.log_prob(center)
            assert np.isfinite(log_p), f"中心{i}的log_prob非有限值"

        weights = np.asarray(gmm_params["weights"], dtype=float)
        assert np.all(weights >= 0.0)
        assert np.isclose(weights.sum(), 1.0, rtol=0.0, atol=1e-12)
        # 物理支持域：rho=exp(z_rho)>0，eta=sigmoid(z_eta)∈(0,1)
        z = np.array([np.log(100.0), np.log(0.05 / 0.95)])
        rho, eta = np.exp(z[0]), 1.0 / (1.0 + np.exp(-z[1]))
        assert rho > 0.0 and 0.0 < eta < 1.0
```
